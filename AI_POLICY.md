# Policy for AI-assisted contributions

This repository follows the [Ansible Community Policy for AI-Assisted
Contributions](https://docs.ansible.com/projects/ansible/latest/community/ai_policy.html).

Contributors may use AI tools when contributing here. You remain responsible for
your work and must follow this repository's contributing guidelines, code of
conduct, and license requirements.

When a significant part of a contribution comes from AI output without
substantial editing, disclose that use as described in the Ansible policy (for
example, an `Assisted-by:` commit trailer).

For AI **agent configuration** in this repository (skills, instruction files,
local agent settings), see [`AI_AGENT_POLICY.md`](AI_AGENT_POLICY.md).
