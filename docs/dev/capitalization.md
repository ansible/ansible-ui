# Capitalization

[PatternFly Capitalization Guidelines](https://www.patternfly.org/ux-writing/capitalization)

- Write navigation items and their corresponding page titles in title case.
- Write all other areas (such as menu items, button text, form field labels, and empty state headings) in sentence case.

## Examples

|           Location |   Case   | Example                                    |
| -----------------: | :------: | ------------------------------------------ |
| Sidebar Navigation |  Title   | Execution Environments                     |
|        Page header |  Title   | Create Execution Environments              |
|    Page breadcrumb |  Title   | Execution Environments                     |
|    Detail page tab |  Title   | Execution Environments                     |
|         Card title |  Title   | Execution Environments                     |
|        Page action | Sentence | Create execution environment               |
|   Form input label | Sentence | Execution environment                      |
|       Detail label | Sentence | Execution environment                      |
|        Empty state | Sentence | You do not have any execution environments |
|       Table Header | Sentence | Execution environment                      |
