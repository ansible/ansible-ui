# Infrastructure

- `Outcome` [Infrastructure and pipelines to accelerate product development and delivery with a quality first mindset](https://issues.redhat.com/browse/ANSTRAT-768)
  - `Initiative`: [PDE Developer Experience](https://issues.redhat.com/browse/ANSTRAT-556)

## PDE Developer Experience - Success Criteria
  - User story: As an Ansible engineer, I want to have an easy way to deploy and use infrastructure and developer environments to help me deliver my duties.
    - Acceptance:
      - An Internal Developer Platform is created and available to all Ansible Engineers members
      - Engineers have click-button workflows to deploy ephemeral environments  such as:
        - AAP environments with GA versions
        - AAP environments with currently developed version candidates
        - AAP environments from arbitrary branch/builds
    - Engineers have click-button workflows to deploy ephemeral infrastructure such as
        - Redis clusters
        - Postgres clusters
        - Any other underlying infra used used by AAP
     - Engineers have capability to deploy long-lived AAP environments for the above options
     - Dashboards for tracking cloud spend and CI/CD pipelines are visible
     - Knowledge bases for engineering teams are accessible from a single location

  - User story: As a developer/PDE, I want to use standardized build systems so I can ensure reliability and consistency using automated processes.
